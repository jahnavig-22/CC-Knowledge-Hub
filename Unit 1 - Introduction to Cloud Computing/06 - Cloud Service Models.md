# Cloud Service Models

## 1. Introduction

Cloud service models describe the types of services provided to users through cloud computing.

The three main cloud service models are:

- Infrastructure as a Service (IaaS)
    
- Platform as a Service (PaaS)
    
- Software as a Service (SaaS)
    

## 2. Infrastructure as a Service (IaaS)

### Definition

IaaS provides virtualized computing resources such as servers, storage, and networking over the internet.

### Features

- Provides virtual machines and storage.
    
- Users can configure operating systems and applications.
    
- Resources can be increased or decreased as needed.
    
- The cloud provider manages the physical infrastructure.
    

### Example

Amazon EC2 provides virtual servers that users can configure for their applications.

### Real-Life Example

A company rents virtual servers instead of purchasing and maintaining physical servers.

## 3. Platform as a Service (PaaS)

### Definition

PaaS provides a platform and tools for developers to build, test, and deploy applications without managing the underlying infrastructure.

### Features

- Provides development tools and runtime environments.
    
- Simplifies application development.
    
- The provider manages the infrastructure and platform.
    
- Developers can focus on writing code.
    

### Example

Google App Engine.

### Real-Life Example

A developer uses an online platform to deploy a web application without managing the physical servers.

## 4. Software as a Service (SaaS)

### Definition

SaaS provides ready-to-use software applications over the internet.

### Features

- Accessed through a web browser or application.
    
- No need to install and maintain the underlying software infrastructure.
    
- The provider manages the application and its infrastructure.
    
- Often available through a subscription.
    

### Examples

- Gmail
    
- Google Docs
    
- Microsoft 365
    

### Real-Life Example

A student uses Google Docs in a browser to create and edit assignments.

## 5. Quick Comparison

|Model|What it provides|Main user activity|
|---|---|---|
|IaaS|Computing infrastructure|Configure servers and applications|
|PaaS|Application development platform|Build and deploy applications|
|SaaS|Ready-to-use software|Use the application|

## 6. Easy Way to Remember

- **IaaS:** Rent the infrastructure.
    
- **PaaS:** Use the platform to build applications.
    
- **SaaS:** Use the finished software.
