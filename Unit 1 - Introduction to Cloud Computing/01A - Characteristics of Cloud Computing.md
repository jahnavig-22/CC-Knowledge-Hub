# Characteristics of Cloud Computing

Cloud computing has five important characteristics commonly described in the NIST definition.

## 1. On-Demand Self-Service

Users can access computing resources whenever they need them without contacting the service provider each time.

**Example:** Creating a virtual machine using a cloud platform.

## 2. Broad Network Access

Cloud services are available over a network and can be accessed using devices such as laptops, tablets, and mobile phones.

**Example:** Opening Google Drive on a laptop or mobile phone.

## 3. Resource Pooling

The cloud provider shares computing resources among multiple users according to their requirements.

**Example:** A cloud data centre serves many customers using shared infrastructure.

## 4. Rapid Elasticity

Computing resources can be increased or decreased quickly according to demand.

**Example:** An online shopping website uses more server capacity during a big sale.

## 5. Measured Service

Cloud resource usage is monitored and measured. Customers may be charged according to the resources they use.

**Example:** Paying for cloud storage or computing capacity based on usage.

## Quick Revision

- **On-demand self-service:** Get resources when needed.
    
- **Broad network access:** Access services through a network.
    
- **Resource pooling:** Shared resources.
    
- **Rapid elasticity:** Scale resources up or down quickly.
    
- **Measured service:** Monitor and measure usage.
