# Cluster Computing Model

## 1. Definition

Cluster computing is a group of computers connected together in the same location that work as a single powerful computer.

## 2. How It Works

1. Computers are connected through a high-speed network.
    
2. Tasks are divided among the computers.
    
3. Each computer processes its assigned task.
    
4. The results are combined to complete the work.
    

## 3. Diagram

Master Node  
↓  
Node 1 | Node 2 | Node 3 | Node 4

The master node coordinates the work, while the other nodes perform the assigned tasks.

## 4. Examples

- Supercomputers
    
- Weather forecasting
    
- Scientific simulations
    

## 5. Advantages

- **High performance:** Multiple computers work together.
    
- **High availability:** Services may continue if one node fails, depending on the cluster design.
    
- **Faster processing:** Tasks can be processed in parallel.
