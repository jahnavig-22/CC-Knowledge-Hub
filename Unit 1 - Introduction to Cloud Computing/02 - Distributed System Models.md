# Distributed System Models

## 1. Introduction

A distributed system consists of multiple computers connected through a network that communicate and coordinate to perform tasks.

## 2. Client-Server Model

In this model, clients request services or resources, and a server processes the requests and sends responses.

**Example:** A web browser requests a webpage from a web server.

**Main components:**

- Client: Requests a service.
    
- Server: Provides the service.
    
- Network: Connects the client and server.
    

## 3. Peer-to-Peer (P2P) Model

In a peer-to-peer model, computers called peers can share resources directly. A peer may act as both a client and a provider of resources.

**Example:** Sharing files directly between computers using a P2P application.

## 4. Cluster Computing

A cluster is a group of connected computers that work together, often appearing as a single system.

**Example:** Multiple servers working together to provide a service.

Read more: [[02A - Cluster Computing]]

## 5. Grid Computing

Grid computing combines resources from multiple computers, potentially in different locations, to solve large computational problems.

**Example:** Computers in different institutions contributing processing power to a research project.

Read more: [[02B - Grid Computing]]

## 6. Quick Comparison

|Model|Main idea|
|---|---|
|Client-server|Clients request services from servers|
|Peer-to-peer|Peers share resources directly|
|Cluster|Closely coordinated computers work together|
|Grid|Distributed resources cooperate on tasks|
