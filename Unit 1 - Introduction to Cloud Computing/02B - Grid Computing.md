# Grid Computing Model

## 1. Definition

Grid computing connects computers located in different geographical locations to solve a large problem.

## 2. How It Works

1. Computers may belong to different organizations.
    
2. Resources are shared through the Internet.
    
3. Each computer performs part of the task.
    
4. The results contribute to solving the larger problem.
    

## 3. Diagram

├── Grid Network

Different computers and organizations contribute resources to the grid.

## 4. Examples

- Scientific research
    
- Medical research
    
- Space research
    

## 5. Advantages

- **Utilizes idle resources:** Makes use of available computing power.
    
- **Cost-effective:** Resources can be shared instead of relying on one powerful computer.
    
- **Suitable for large-scale problems:** Multiple computers contribute to solving complex tasks.
    

## 6. Cluster Computing vs Grid Computing

|Cluster Computing|Grid Computing|
|---|---|
|Computers are usually located in the same place.|Computers can be in different geographical locations.|
|Computers work together as one powerful system.|Computers share resources to solve a large problem.|
|Example: Supercomputers.|Example: Scientific research.|
