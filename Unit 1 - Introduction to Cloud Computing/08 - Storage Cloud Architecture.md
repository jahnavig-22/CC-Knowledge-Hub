# Storage Cloud Architecture

## 1. Definition

Storage Cloud Architecture describes how data is stored and organized in cloud computing systems.

Cloud storage allows users to store and access data over the internet without depending only on local storage devices.

## 2. Types of Cloud Storage

According to the uploaded class presentation, there are three main types of cloud storage:

### 2.1 Object Storage

**Definition:** Object storage stores data as individual objects. Each object contains the data, metadata (information about the data), and a unique ID.

**Used for:**

- Photos
    
- Videos
    
- Music
    
- Backups
    

**Examples:**

- Google Photos
    
- Amazon S3
    
- Dropbox
    

**Real-life example:** Storing photos online so that they can be accessed from different devices.

### 2.2 Block Storage

**Definition:** Block storage divides data into smaller blocks and stores each block separately. The blocks are used together when the data is accessed.

**Used for:**

- Databases
    
- Virtual machines
    
- Operating systems
    

**Real-life example:** A bank database uses block storage when it needs fast access to data.

### 2.3 File Storage

**Definition:** File storage organizes data into files and folders, similar to how files are arranged on a computer.

**Used for:**

- Documents
    
- PDFs
    
- Word files
    
- Shared folders
    

**Examples:**

- Google Drive folders
    
- OneDrive
    
- Shared office files
    

**Real-life example:** Organizing college assignments into separate folders in cloud storage.

## 3. Quick Comparison

|Type|How data is stored|Common uses|
|---|---|---|
|Object Storage|Individual objects with metadata and unique IDs|Photos, videos, backups|
|Block Storage|Separate blocks of data|Databases, virtual machines|
|File Storage|Files and folders|Documents, PDFs, shared files|

## 4. Advantages of Cloud Storage

- Data can be accessed over the internet.
    
- Storage capacity can be increased as needed.
    
- Files can be shared with other users.
    
- Data can be accessed from different devices.
    
- Cloud services can support backup and recovery.
    

## 5. Real-Life Example

A student stores assignments in Google Drive:

1. The student uploads a document.
    
2. The cloud service stores the document.
    
3. The student can access it later using an internet-connected device.
    
4. The document can be shared with classmates or teachers.
    

## 6. Quick Revision

- **Object storage:** Stores data as objects.
    
- **Block storage:** Stores data in blocks.
    
- **File storage:** Stores data in files and folders.
