# Cloud Computing Architecture

## 1. Definition

Cloud Computing Architecture is the structure of frontend (client) and backend (provider) components that define how cloud services are delivered, managed, and accessed over the internet.

Cloud Computing Architecture is divided into two main parts:

- Frontend
    
- Backend
    

## 2. Frontend

### Definition

The Frontend is the user-facing part of the cloud. It includes everything users interact with to access cloud services.

### Components

- Web browsers
    
- Mobile applications
    
- Desktop applications
    
- Graphical User Interfaces (GUI)
    

### Example

Using Google Chrome to access Google Drive.

## 3. Backend

### Definition

The Backend is the service provider's side of the cloud. It contains the resources and technologies required to deliver cloud services.

### Components

- Servers
    
- Storage systems
    
- Databases
    
- Security mechanisms
    
- Traffic management
    
- Virtualization technologies
    

### Example

Cloud servers process a user's request and retrieve the required file from storage.

## 4. Components of Cloud Computing Architecture

### 4.1 Client Infrastructure

Client Infrastructure is part of the frontend. It contains the applications and user interfaces required to access the cloud platform.

### 4.2 Application

The Application is a backend component that provides services according to client requirements.

### 4.3 Service

Service refers to the three main types of cloud-based services:

- IaaS
    
- PaaS
    
- SaaS
    

### 4.4 Runtime Cloud

Runtime Cloud provides the platform where cloud services and virtual machines run.

### 4.5 Storage

Cloud storage provides flexible and scalable space for storing user data. The backend manages, organizes, and protects this data.

### 4.6 Infrastructure

Cloud Infrastructure includes the hardware and software components of the cloud, such as servers, storage, and network devices.

### 4.7 Management

Management controls and coordinates backend components, including applications, services, storage, and infrastructure, to ensure efficient operation.

### 4.8 Security

Security includes tools and systems that protect cloud data and services from unauthorized access and attacks.

### 4.9 Internet

The Internet acts as a communication bridge between the frontend and backend, allowing users to access cloud services.

## 5. Working of Cloud Computing Architecture

1. The user opens a cloud application through a browser or mobile app.
    
2. The frontend sends the user's request through the internet.
    
3. The backend receives and processes the request.
    
4. The required application, computing resources, or stored data is accessed.
    
5. The result is returned to the frontend and displayed to the user.
    

## 6. Real-Life Example

When a student opens Google Drive:

- **Frontend:** The browser or mobile app used by the student.
    
- **Internet:** Connects the student's device to Google's cloud services.
    
- **Backend:** Processes the request and manages the files.
    
- **Storage:** Stores the student's documents.
    
- **Security:** Helps protect the student's files and account.
    

## 7. Quick Revision

- **Frontend:** The part users interact with.
    
- **Backend:** The provider's side that processes requests and delivers services.
    
- **Internet:** Connects the frontend and backend.
    
- **Storage:** Stores user data.
    
- **Management:** Coordinates cloud resources.
    
- **Security:** Protects cloud resources and data.
