# Introduction to Cloud Computing

## 1. Definition

Cloud computing is a technology that allows users to access computing resources such as servers, storage, databases, networking, and software over the internet.

## 2. History of Cloud Computing

- **Mainframe computing:** Many users shared the computing power of a central computer.
    
- **Distributed computing:** Multiple computers worked together to complete tasks.
    
- **Virtualization:** One physical computer could run multiple virtual machines.
    
- **Cloud computing:** Computing resources became available over the internet on demand.
    

## 3. How Cloud Computing Works

1. A user requests a resource through a computer or mobile device.
    
2. The request travels through the internet.
    
3. A cloud provider supplies the required computing resource.
    
4. The user accesses the resource without managing the physical infrastructure.
    

## 4. Real-Life Example

Google Drive lets users store files online and access them from different devices using the internet.

## 5. Advantages

- Access from anywhere with an internet connection.
    
- Less need to purchase physical hardware.
    
- Resources can be increased or decreased as needed.
    
- Easy storage and sharing of files.
