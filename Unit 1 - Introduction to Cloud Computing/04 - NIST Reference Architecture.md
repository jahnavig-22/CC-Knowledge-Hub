# NIST Cloud Computing Reference Architecture

## 1. Introduction

NIST stands for National Institute of Standards and Technology.

The NIST Cloud Computing Reference Architecture describes the major actors in a cloud environment and explains their responsibilities.

## 2. Five Main Actors

### 1. Cloud Consumer

**Definition:** A cloud consumer is a person or organization that uses cloud services.

**Responsibilities:**

- Selects cloud services.
    
- Uses cloud applications and storage.
    
- Pays for cloud services.
    

**Examples:**

- A student using Google Drive.
    
- A company using Microsoft Azure.
    

### 2. Cloud Provider

**Definition:** A cloud provider is an organization that offers cloud services to customers.

**Responsibilities:**

- Provides infrastructure.
    
- Manages servers and storage.
    
- Maintains security and availability.
    

**Examples:**

- Amazon Web Services (AWS).
    
- Microsoft Azure.
    
- Google Cloud Platform (GCP).
    

### 3. Cloud Broker

**Definition:** A cloud broker acts as an intermediary between the cloud consumer and cloud provider.

**Responsibilities:**

- Helps select suitable cloud providers.
    
- Manages multiple cloud services.
    
- Helps improve service management.
    

**Example:** A company that helps an organization choose suitable cloud services.

### 4. Cloud Carrier

**Definition:** A cloud carrier provides the network connection between the cloud provider and the cloud consumer.

**Responsibilities:**

- Transfers cloud data.
    
- Provides internet connectivity.
    
- Supports reliable communication.
    

**Examples from the notes:**

- Airtel.
    
- Jio.
    
- BSNL.
    

### 5. Cloud Auditor

**Definition:** A cloud auditor independently evaluates cloud services.

**Responsibilities:**

- Checks security.
    
- Verifies compliance.
    
- Audits cloud performance.
    

**Example:** A third-party security auditing company.

## 3. Simple Diagram

Cloud Consumer

Cloud Provider

- **Auditor:** Evaluates cloud services.
