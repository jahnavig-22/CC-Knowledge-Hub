# Identity and Access Management (IAM)

## 1. Introduction

Identity and Access Management (IAM) is a security system used to manage the identities of users and control their access to cloud resources.

It ensures that only authorized users can access specific applications, data, and services.

## 2. Objectives of IAM

- Identify and authenticate users.
    
- Control access to cloud resources.
    
- Prevent unauthorized access.
    
- Protect confidential information.
    
- Maintain records of user activities.
    

## 3. Main Components of IAM

### 3.1 Identity

An identity represents a user, application, service, or device that needs access to cloud resources.

**Example:** A student account used to access a college portal.

### 3.2 Authentication

Authentication verifies the identity of a user.

Common methods include:

- Passwords
    
- One-time passwords (OTPs)
    
- Biometric verification
    
- Multi-factor authentication (MFA)
    

### 3.3 Authorization

Authorization determines what an authenticated user is allowed to do.

**Example:** A student can view marks, while a faculty member may be allowed to enter marks.

### 3.4 Access Control

Access control applies rules that determine which resources a user can access and what actions they can perform.

### 3.5 Auditing

Auditing records and reviews activities performed by users and administrators.

It helps identify suspicious activity and supports security investigations.

## 4. Types of Access Control

### 4.1 Role-Based Access Control (RBAC)

Permissions are assigned according to a user's role.

**Example:** An administrator can manage users, while a student can view personal academic details.

### 4.2 Attribute-Based Access Control (ABAC)

Access decisions are based on attributes such as user role, location, resource type, or time.

### 4.3 Mandatory Access Control (MAC)

Access is controlled by centrally defined security policies and classifications.

### 4.4 Discretionary Access Control (DAC)

The owner of a resource can decide which users are allowed to access it.

## 5. Benefits of IAM

- Improves cloud security.
    
- Reduces unauthorized access.
    
- Supports centralized user management.
    
- Helps enforce least-privilege access.
    
- Provides records for monitoring and auditing.
    

## 6. Real-Time Example

In a college management system, students can view their attendance and results, faculty members can update academic records, and administrators can manage accounts. IAM helps ensure that each user receives only the permissions required for their role.

## 7. Conclusion

IAM is an important part of cloud security. It manages identities, verifies users, controls permissions, and monitors access to protect cloud resources.
